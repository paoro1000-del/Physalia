# カナリアページ作製キット

Python標準ライブラリだけで動く、カナリア用ホームページと記録サーバーのサンプルです。追加パッケージは不要です。

## PC内で動作確認

1. Python 3.10以降を用意します。
2. ZIPを展開し、展開先で `python server.py` を実行します。
3. `http://127.0.0.1:8765/` をブラウザーで開きます。
4. アクセスのたびに、サーバーがHTTP要求を `logs/contacts.jsonl` に記録します。ブラウザー情報と位置情報は、イベントIDで要求記録と照合できます。
5. 終了はターミナルで Ctrl+C です。

## 外部公開

初期設定は `127.0.0.1` のみで待ち受けます。HTTPS対応のリバースプロキシから `127.0.0.1:8765` へ転送して公開してください。Pythonサーバーを直接インターネットへ公開したり、`0.0.0.0` で待ち受けたりしないでください。ブラウザーの位置情報APIにはHTTPSが必要です。

プロキシ経由では、Python側の接続元IPは通常プロキシのIPになります。訪問者IPが必要な場合は、信頼するプロキシ側のアクセスログを確認してください。このサンプルは偽装可能な `X-Forwarded-For` を信用しません。

## 記録する情報

- HTTP要求：UTC時刻、接続元IP、HTTPメソッド・版、User-Agent、Accept-Language、Accept、および対応ブラウザーが送るSec-CH-UA/Sec-Fetchヘッダー。
- ブラウザー情報：言語、ブラウザー・OSの情報、タイムゾーン、画面サイズ、CPUスレッド数、プラグイン/MIME種別、通信状態、WebGL/GPU情報、タッチ対応、表示設定など、ブラウザーが提供する値。ブラウザーにより取得できる項目は異なります。
- 位置情報：ページに説明を表示したうえでブラウザーに許可を求め、許可された場合だけ緯度・経度・精度などを記録します。拒否してもページを表示します。

Cookie、ページ内容、ファイル、カメラ、マイク、他サイトのデータは読み取りません。値は省略・偽装されることがあります。記録からサンドボックス使用や攻撃者本人を断定することはできません。JSONLログには自動ローテーション・削除がないため、アクセス制限、保持期間、バックアップ、削除を運用者が設定してください。ログや位置情報は機微情報として扱ってください。このサンプルは隔離した自分の環境で利用し、第三者のサイトを装わないでください。
