# はじめに

## ローカルポートの設定

プロジェクト直下の `app_config.json` の `port` に、1〜65535の利用可能なポート番号を指定します。既定値は8765です。変更後、Physaliaを再起動してください。起動時に `--port` を指定すると設定ファイルより優先されます。`--port 0` を指定した場合は、その起動時にOSが空きポートを選びます。

アプリは起動済みです。左側の「対策紹介とサンプル生成」から始めましょう。

## 1. サンプルを作成する

対策ごとの仕組みや効果、設定上の注意は、画面でその対策を選んだときに確認できます。ガイドでは基本的な操作だけを説明します。

1. 左側の「対策紹介とサンプル生成」を開きます。
2. 心配なことを選んで候補を絞り、対策カードを選びます。
3. 画面に表示される説明と設定項目を確認します。
4. 必要な設定を行い、「ファイルを生成」を押します。
5. 保存したファイルの確認は、次の「2. 保存したファイルを確認する」を参照します。

「開発中」と表示された対策は初版では選択・生成できません。「説明のみ」の対策は仕組みの紹介で、ファイル生成や本番環境の変更は行いません。

生成されるデータは架空で、ファイルはブラウザーから保存されます。アプリがWebサイトへ配置することはありません。本番環境には投入せず、自分が管理する隔離環境で確認してください。

## 2. 保存したファイルを確認する

ダウンロード名は対策に合わせた`Physalia_*`形式です。必要なら保存後に変更できます。ZIP内のファイル名は、`.env`など形式上必要な名前のままです。

### 保存とプレビュー

- ファイルはブラウザーのダウンロード先に保存されます。自動保存されない場合は、生成結果に表示されるファイル名リンクを押してください。
- HTMLとPDFは、それぞれ「新しいタブでHTMLをプレビュー」「新しいタブでPDFをプレビュー」から確認できます。単体HTMLのプレビューは表示確認用で、Webサイトへの配置は行いません。
- カナリアファイルのHTMLは、リンク・ボタン・アイコン・ページ送りなどから誘導方法を選べます。カナリアURLへの要求はクリック時に発生します。「ページ全体」を選んだ場合は、ページ内のどこを押してもリンクが開きます。プレビューを開いただけでは接触記録は発生しません。

### 形式ごとの確認

- **Excel・PowerPoint:** 表のセルには架空の通常URLを表示し、カナリアURLはハイパーリンク先にだけ保存します。監視先へ接続せず確認するには、セルをクリックせず、右クリックしてリンク先を編集してください。セルをクリックすると要求が送られる場合があります。
- **メールアドレス表示:** 選択したセルには通常のメールアドレスを表示し、リンク先だけをカナリアURLにします。クリックするとブラウザーでURLが開き、メールは送信されません。
- **デコイ・ポータル:** 配置用ZIPには`index.html`と`documents`フォルダーが入っています。Webサイトとして試す場合は、ZIPを展開して両方を同じフォルダーに手動配置します。監視URLがなければ6件の架空文書が開きます。URLがある場合は1件が監視先へつながり、残り5件は文書を開きます。
- **ファイル・データベースのプレビュー:** カナリアファイルは10件ずつ表示し、カナリアレコードがあれば該当ページを開きます。ページ送りで全件を確認できます。データベースのプレビューは先頭10件です。全件を確認する場合は、ダウンロードしたSQLiteを信頼できるビューアで開いてください。
- **`.env`:** ZIPを展開します。Windowsでは右クリックして「すべて展開」、macOSではダブルクリックし、展開先の`.env.development`を確認してください。

### エンクリプテッド・ディープ・ネストのZIP

1. ダウンロードした`Physalia_*.zip`自体が、最初のAES暗号化ZIPです。通常のZIPを先に展開する必要はありません。AES暗号化ZIPに対応したソフトで開いてください。
2. `*_zip_passwords.txt`から該当パスのパスワードを探し、入力します。この一覧はサンプル検証専用です。パスワードが含まれるため、デコイとは分けて保管し、配置・公開しないでください。
3. ZIPの暗号化はファイル内容を保護しますが、ファイル名とフォルダー構造は隠しません。7-Zipで現在のZIP内の一覧が見えるのは通常の動作です。内側のZIPの一覧は、そのZIPをパスワードで開くまで見えません。このツールは一覧を隠す7zヘッダー暗号化には対応していません。

プロジェクト内に一時保管する場合は、リポジトリ直下の`generated/`を使うとGit管理から除外されます。公開前には除外設定だけに頼らず、`git status --short`で登録対象を確認してください。

## 3. 配置する場合

最初は本番環境ではなく、自分が管理する試験用サイトまたは別サーバーで試してください。これは、本番サイト・本番データベース・実際のユーザーアカウントから切り離した場所です。Webサイトで公開するファイルだけを配置し、本番の認証情報やデータは置かないでください。`.operator.json`や`.inventory.json`などの管理者専用ファイルは、Webサイトから誰でも取得できるフォルダーの外に保管してください。生成物には入力したカナリアURLが含まれる場合があるため、公開GitHubリポジトリへ登録しないでください。ログイン制限、HTTPS、アクセス記録、通知先は配置先で設定します。
