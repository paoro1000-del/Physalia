# Physalia

[English](README_en.md) | 日本語

ローカル環境で、セキュリティ検証用の架空デコイファイルやサンプルを生成するツールです。生成物は自動配置されず、本番認証やネットワーク監視サービスとも連携しません。ディレクトリ・メイズ、エンコーディング・メイズ、インフィニット・ストリーム、ランサムウェア・デコイフラッドは開発中のため、初版では選択・生成できません。

## 準備と起動

Python 3.11〜3.14を用意し、ターミナルで次のコマンドを実行してソースを取得します。

```sh
git clone https://github.com/paoro1000-del/Physalia.git
cd Physalia
```

取得したフォルダーで、利用するOSに応じて起動してください。

**Windows（PowerShell）**

初めて使う場合は、次の準備を一度だけ行ってください。

1. [Python公式の3.14.10ダウンロードページ](https://www.python.org/downloads/release/python-31410/)を開きます。
2. ページ下部の **Windows installer (64-bit)** をダウンロードして実行します。
3. インストーラーの **Install Now** を選びます。インストールが終わったら、起動スクリプトを実行してください。

準備ができたら、次のいずれかでアプリを起動します。

- `start_windows.bat` をダブルクリック
- PowerShellで次を実行

```powershell
.\start_windows.bat
```

Windows版はアプリ用のウィンドウを別に開きます。停止するときはそのウィンドウで `Ctrl+C` を押してください。終了確認は表示せず、アプリがそのまま終了します。

**macOS / Linux（ターミナル）**

```sh
sh ./start_unix.sh
```

Linuxでは、Python 3.11〜3.14と `venv` が使える状態にしてから起動してください。ディストリビューションによっては `venv` が別パッケージ（例：`python3-venv`）です。起動スクリプトは対応するPythonを探し、見つからない場合は必要な導入方法を表示します。各OSの導入手順は[クイックスタートガイド](docs/quickstart_ja.md)を参照してください。

起動スクリプトは仮想環境を作成し、固定済みの依存パッケージを初回インストールしてアプリを起動します。ブラウザーで画面が開きます。初回のパッケージ取得にはインターネット接続が必要です。

アプリのログはプロジェクト直下の`logs/YYYYMMDD_app.log`に日付ごとに記録します。起動時に7日以上経過したログを削除します。ログレベルはルートの`app_config.json`で`DEBUG`、`INFO`、`WARNING`、`ERROR`から指定でき、既定は`INFO`です。`DEBUG`ではHTTP経路の分類や例外の詳細も記録します。リクエスト本文、URLパス、カナリアトークンは記録しません。

HTTP要求の完了時には、相関ID、メソッド、安全な経路分類、HTTP状態、応答バイト数、所要時間、結果をINFOに1行で記録します。例: `request_completed id=… method=GET route=home status=200 response_bytes=… elapsed_ms=… outcome=ok`。`DEBUG`では処理段階と例外スタックも記録します。リクエスト本文、URLパス、クエリ、カナリアトークン、接続元アドレスは記録しません。

## できること

セキュリティ対策ごとに、狙いや仕組み、導入時の検討点をツール内で解説し、サンプルファイルやコードを生成します。内容を確認しながら、自組織の環境や運用に取り入れる価値があるかを検討するためのツールです。

開発中の方式は、画面・APIから選択または生成できません。既存の配置物や設計資料に関する参照情報は、各ガイドに明記します。

パス・メイズは通常の有限フォルダーと架空ファイルを生成し、人手の調査や重要ファイル検索アプリが架空ファイルも候補に含める場合の選別作業を増やして、本物が埋もれる可能性を狙います。検索アプリによる分類・自動除外や一括・並列処理で効果は弱まり、遅延や見落としは保証されません。スパース・デコイは初期割り当てが小さく論理サイズが大きい架空ファイルです。疎領域を認識せず全域を処理する場合に限り追加負荷が生じる可能性がありますが、部分処理やサイズ除外で効果は弱まります。書き込みやコピーで論理サイズ分の容量を消費し、業務や復旧に影響する恐れがあるため、ランサムウェアを止める対策とは扱わず、空き容量を監視してください。拡張子は見た目だけで、内容はその形式に準拠しません。

スパース・デコイは、別OSへの配置用に非圧縮TARも生成できます。GNU PAX sparse 1.0形式で論理サイズとデータ範囲だけを記録し、大きな空き領域はアーカイブに格納しません。配置先ではGNU tarまたはbsdtarで展開します。展開手順と容量確認方法は[クイックスタートガイド](docs/quickstart_ja.md)を参照してください。汎用の展開ツールでは論理サイズ分の領域を割り当てる場合があります。運用者専用一覧は分けて保管してください。

生成物は検証・導入判断の参考資料です。実環境への配置や監視サービスとの連携は利用者が行います。

同じPCでの確認用カナリアページURLはPhysaliaの起動時に自動で用意されます。稼働中の接触と、送信されたIP・ブラウザー情報などは左メニューの「カナリアページ」に表示され、最大500件をメモリに保持します。`127.0.0.1`を使うため、別PCに配置したファイルからは接触できず、接続元IPも通常は`127.0.0.1`です。ログはアプリ終了時に消去され、初期URLは再起動後に変わります。同じ起動中のサンプルはURLを共有します。本番で使う場合は、HTTPSで外部ネットワークからアクセスできる場所にカナリアページを公開し、そのカナリアページURLをサンプルに設定してください。

ブラウザーでカナリアページを開くと、対応する範囲で画面サイズ、タイムゾーン、CPU数の目安、GPU情報や自動操作フラグなども記録します。JavaScriptが動かないアクセスはHTTP情報のみです。値は欠落・偽装され得るため、サンドボックスや攻撃者の特定には使えません。利用許可を得た環境で、適用法令や組織の規程を確認して運用してください。

カナリアページではブラウザーに位置情報の利用許可も求め、許可された場合は位置・精度などを接触ログに記録します。既に許可済みなら確認画面が出ない場合があります。拒否・非対応の場合も接触自体は記録されます。ブラウザーやOSの位置情報サービスがネットワークを利用する場合があります。

独自のカナリアページを隔離環境に公開する場合は、カナリアページ下部からホームページ作製キットをダウンロードできます。HTML/CSS/JavaScriptのページ、Python標準ライブラリの記録サーバー、日本語・英語の手順が入っています。公開時はHTTPSリバースプロキシとアクセス制御を構成してください。

## 注意

生成したデコイファイルや設定を公開Gitにアップロードしないでください。生成されたデコイファイルやデコイパターンが公開されると、実物との比較でデコイを見破られるリスクが高まります。生成物は公開せず、隔離した検証環境で扱ってください。
